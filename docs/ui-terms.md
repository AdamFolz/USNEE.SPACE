# Термины UI

## Словарь

| Используем | Не используем |
|---|---|
| Запись | приём, фиксация |
| История | лента, журнал |
| Прогресс | достижения |
| Состояние | самочувствие |

## Правила

Действуют для любого текста, включая новые экраны.

- Обращение «ты», нижний регистр в подписях
- Без морали и оценок
- Кнопка: 1-2 слова, глагол в инфинитиве или существительное
- Пустое состояние тёплое, а не «ничего нет»
- Ошибка без драмы, без «упс»

## Новая сущность

Экран или кнопка без термина в словаре:

1. Предложить 2-3 варианта термина
2. Выбрать один по правилам выше
3. Дописать строку в словарь
4. Только потом писать текст

## Где что применяется

- Словарь — источник истины для существующих сущностей
- Правила — всегда, для любого нового текста
- Heretic — онбординг, пустые состояния, лендинг. Не для кнопок и заголовков
