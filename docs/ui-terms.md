## Правила по кнопкам

Действуют для любого текста, включая новые экраны.

- Обращение «ты», нижний регистр в подписях (кроме имён собственных и аббревиатур: PIN, NORS).
- Кнопка: 1–2 слова, глагол в инфинитиве или существительное. Примеры из кода: «Записать», «Отменить запись», «Сохранить копию», «Восстановить», «Закрыть партию», «Сменить PIN», «Пропустить», «Назад», «Далее», «Начать».
- Без морали и оценок: никаких «хватит?», «трезво», «молодец», «плохо». Факт — да, вердикт — нет.
- Пустое состояние тёплое, а не «ничего нет»: «Появится после первой записи» (IntervalCard).
- Ошибка без драмы, без «упс»: «Неверный PIN», «PIN не совпадает. Попробуй ещё раз.»
- Деструктив — двойное подтверждение с явной ценой: deleteLabels «Удалить все данные» → «Точно?» → «Это навсегда.»; восстановление копии — отдельное подтверждение.
- Экспорт при недоступном WebCrypto — честный отказ: «Экспорт прерван — данные НЕ сохранены в открытом виде. Открой приложение по HTTPS и повтори.» Не молчать, не сохранять открытый текст.
- Онбординг: «С чего начать», «Пропустить» (aria «Пропустить знакомство»), «Назад» / «Далее» / «Начать». Тон — факт о функции, не обещание результата.
- Лендинг и онбординг обязаны нести юрдисклеймер «инструмент самонаблюдения, не поощрение употребления» (PRODUCT.md:59). Сейчас отсутствует — см. «Находки».

## Запреты (сводно)

1. Мораль/оценки употребления: «трезво», «хватит?», «сорвался», «чисто» как похвала.
2. Медицинские обещания: «поможет», «безопасная доза», «выведет быстрее».
3. Автодействие в SOS: любые формулировки, будто приложение звонит/пишет само.
4. «Упс», «ой», восклицания в ошибках, драма («катастрофа», «всё пропало»).
5. Англицизмы в подписях при живом русском аналоге: bulk, stats, settings, home.
6. Переименование сущностей словаря без строки в этом файле.
7. Gamification-давление: «ты теряешь ранг», «не подведи», таймеры-угрозы. Ранг растёт от регулярности, а не от дозы — и это говорится прямо (Progress:242, Profile:637).

## Новая сущность

Экран или кнопка без термина в словаре:

1. Предложить 2–3 варианта термина.
2. Выбрать один по правилам выше.
3. Дописать строку в словарь с указанием места в коде.
4. Только потом писать текст.

## Где что применяется

- Словарь — источник истины для существующих сущностей.
- Правила — всегда, для любого нового текста.
- Находки — очередь решений владельца, не руководство к немедленной правке.
- Heretic — онбординг, пустые состояния, лендинг. Не для кнопок и заголовков.
