# docs/current — текущее состояние

## Перед работой в старой сессии

Сессии OpenCode живут дольше кода. Если продолжить старую сессию, агент поднимет устаревший контекст и может перезаписать свежие правки старым кодом.

Перед продолжением любой сессии старше недели:

```powershell
powershell -File tools\check-session-freshness.ps1
```

Скрипт read-only: находит сессии по текущему каталогу старше 7 дней и печатает файлы, изменённые позже сессии (код выхода 1 — расхождения есть).

- Расхождений нет — можно продолжать.
- Файлы новее сессии — начинай новую сессию и вводи агента в курс через `.agents/HANDOFF.md`: что сделано, что осталось, какие решения приняты. Коротко, фактами, со ссылками на файлы.
- Заголовки сессий размечены значками: 🔴 — сессия старше правок в проекте, 🟡 — проект без активности больше 14 дней, 🟢 — свежая, ⚪ — черновик.

Параметры: `-Directory <путь>`, `-Days <N>`.

## Проверка после каждого деплоя

```powershell
curl.exe -sS -o NUL -w "%{http_code}\n" https://usnee.space/
```

Ожидать `200`, затем глазами открыть первый экран: должен быть онбординг, а не текст «Приложение не загрузилось». Boot-заглушка живёт в `index.html` вне Vitest — тесты регрессию такого класса не ловят.
